Courses

Add a course: type the course name and code, pick the programme and level, name the lecturer, then mark its delivery — online (yes/no), field work (yes/no), and hours per session. One row per course: the class composition (sections) is derived automatically from the Cohorts tab for that programme and level, and a course with a combined A+B class above 90 students is automatically split into one class per section, each keeping the full teaching hours (TPC). Courses shared with another programme (e.g. CE 158/PM 138) are marked with a "!" badge — their class composition is kept as-is and can be seen under Advanced fields. Use "Advanced fields" only to set the teaching hours (TPC), sections, credits, and engine values — these stay the same every semester unless the department changes them.
